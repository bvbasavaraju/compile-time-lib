== String

There are 4 parts here.

* <<_read_only_string>> => compile-time string type and user-defined literal
* <<_algorithms_2>> => operations which create new compile-time strings
* <<_hash>> => runtime and compile-time compatible string hashing
* <<_registrar>> => a duplicate-free registry of hashed string types
